# 06 管理后台规范

## 后台定位

第一版后台只做门店运营必需功能，不做复杂中台。

## 页面清单

```text
/dashboard                 数据概览
/products                  商品管理
/group-buys                团购管理
/orders                    订单管理
/refunds                   退款管理
/leader-applications       开团人审核
/commissions               开团服务奖励
/withdrawals               提现审核
/communities               社区管理
/pickup-stores             自提点管理
```

## 商品管理

功能：

- 商品列表
- 新增商品
- 编辑商品
- 上架/下架
- 设置库存
- 设置是否支持开团
- 设置开团服务奖励类型
- 设置开团服务奖励值

## 团购管理

功能：

- 团购列表
- 团购详情
- 查看开团人
- 查看参与订单
- 手动取消团购
- 标记备货中
- 标记待自提
- 标记已履约

## 订单管理

功能：

- 订单列表
- 订单详情
- 按状态筛选
- 按自提时间筛选
- 标记备货中
- 标记待自提
- 标记已自提
- 标记已配送
- 标记完成
- 导出分拣单 CSV

## 退款管理

功能：

- 退款列表
- 查看退款原因
- 审核通过
- 审核拒绝
- MOCK 模式模拟退款成功

## 开团人审核

功能：

- 申请列表
- 查看申请人手机号、社区
- 审核通过
- 审核拒绝
- 审核备注

审核通过后：

- User.role = leader

## 开团服务奖励

功能：

- 奖励列表
- 按开团人筛选
- 按团购筛选
- 按状态筛选
- 冻结奖励
- 解冻奖励
- 查看扣减记录

文案统一使用“开团服务奖励”。

## 提现审核

功能：

- 提现申请列表
- 审核通过
- 审核拒绝
- 标记已支付

第一版不做自动打款。

## 社区管理

功能：

- 新增社区
- 编辑社区
- 启用/禁用

## 自提点管理

功能：

- 新增自提点
- 编辑自提点
- 启用/禁用

## 鉴权

第一版后台使用 `ADMIN_TOKEN`。

请求头：

```text
Authorization: Bearer <ADMIN_TOKEN>
```

## UI 要求

- 使用 React + Vite + Ant Design
- 列表页先实现基础表格
- 表单先实现基本字段
- 不追求精美，优先可用和稳定
