# 00 项目说明

## 项目名称

社区甄选小程序 / community-selection-miniapp

## 项目背景

当前业务已有：

- 一家实体店铺
- 线下有稳定货源
- 已接入美团
- 已有微信群
- 有本地社区用户基础

当前缺少：

- 微信小程序交易入口
- 社区团购系统
- 开团人一级服务奖励系统
- 退款和开团失败自动处理
- 后台管理和分拣导出

## 项目定位

本项目定位为：

> 本地实体店私域小程序 + 社区开团系统 + 一级开团服务奖励 + 自提配送履约。

不是完整电商平台，也不是多商户商城，也不是多级分销系统。

## 第一版目标

第一版只跑通核心闭环：

1. 门店和微信群导流到小程序
2. 用户浏览商品
3. 用户发起开团或参与团购
4. 用户微信支付
5. 团购达到条件后成团
6. 团购失败后自动退款
7. 门店分拣、自提或配送
8. 售后退款
9. 开团人获得一级开团服务奖励
10. 奖励 T+7 后可提现
11. 后台人工审核提现

## 不做范围

第一版不做：

- 多商户
- 多门店复杂体系
- 多级分销
- 会员储值
- 积分商城
- 优惠券复杂体系
- 直播
- 秒杀
- 美团订单自动同步
- 自动微信零钱打款
- 复杂 BI 报表

## 核心用户角色

### 普通用户

- 浏览商品
- 参团下单
- 发起退款
- 查看订单

### 开团人

- 申请成为开团人
- 发起团购
- 分享团购
- 查看自己的开团
- 查看开团服务奖励
- 发起提现申请

### 门店/后台管理员

- 管理商品
- 管理订单
- 管理团购
- 审核退款
- 审核开团人
- 审核提现
- 导出分拣单

## 商业原则

实体店做信任，美团做曝光，微信群做种草，小程序做成交，开团人做一级推广。
