# L55 老会员手机号导入规格

## 目标

运营人员可通过 CSV 或 `.xlsx` 导入老会员手机号，系统先预览、校验、去重，再由 `super_admin` 显式确认。确认仅建立 `LEGACY_FIRST_YEAR_FREE` 资格；`MEMBERSHIP_ENABLED=false` 时不启用折扣。

## 安全与业务边界

- 手机号是账户匹配键，不使用订单收货手机号认领资格。
- 接受 `+86`、空格和短横线，最终只接受有效大陆手机号。
- 数据库仅保存 HMAC-SHA256 指纹和脱敏手机号，不保存导入文件中的完整手机号。
- HMAC 密钥统一由 `MEMBER_PHONE_HMAC_SECRET` 配置，至少 32 个字符；缺失时导入功能失败关闭。
- 上传限制 5 MiB、10,000 行；只读取 Excel 第一工作表；拒绝公式单元格。
- 文件哈希、来源说明、操作者、确认者和统计结果可审计。
- 跨批次重复手机号只产生一份资格；同一批次重复行在预览中明确展示。
- 已存在用户按其账户手机号匹配；未匹配资格可在用户完成可信手机号绑定后调用认领函数。
- `LEGACY_FIRST_YEAR_FREE` 每个手机号只能发放一次；未使用资格可撤销，已使用资格不可撤销。
- API 与后台仅返回脱敏手机号；正式导入只允许 `super_admin`。

## 两阶段流程

1. 上传 CSV/Excel 和来源说明，解析后创建 `preview` 批次。
2. 返回脱敏行、有效/重复/无效/已匹配/待匹配统计。
3. `super_admin` 确认批次后，在事务内幂等创建资格并把批次置为 `confirmed`。
4. 后台可查看批次和脱敏行；未使用资格允许撤销。

## 文件格式

首行必须包含以下任一手机号列名：`手机号`、`手机号码`、`phone`、`mobile`。CSV 使用 UTF-8；Excel 读取第一工作表。其他列不进入数据库。

## 功能开关

导入资格与会员优惠分离。工作台固定展示“会员优惠关闭时仅建立资格”；本阶段不实现 88 元会员购买或折扣计算。
