# L23 MVP 验收清单

## 1. MVP 范围说明

当前 MVP 已覆盖：商品列表、商品详情、社区选择、自提点选择、普通购买、开团购买、mock 支付、我的订单、订单详情、自提凭证、售后申请、售后进度、财务对账、运营看板、开团服务奖励后台核算。提现/税务仍为人工审核流程，提现由后台人工审核并手动标记已打款，税务为人工审核 / 占位，不自动报税。

## 2. 用户端主链路验收

- [ ] 打开小程序。
- [ ] 设置 API_BASE_URL。
- [ ] 设置 mock 用户身份。
- [ ] 进入商品列表。
- [ ] 选择社区。
- [ ] 选择自提点。
- [ ] 查看商品详情。
- [ ] 普通购买下单。
- [ ] mock 支付。
- [ ] 进入我的订单。
- [ ] 查看普通订单详情。
- [ ] 查看自提凭证。
- [ ] 发起售后。
- [ ] 查看售后进度。
- [ ] 参与开团。
- [ ] mock 支付。
- [ ] 查看开团订单详情。

## 3. 后台验收

- [ ] 管理端商品可见。
- [ ] 订单可见。
- [ ] 售后可见。
- [ ] 财务对账可见。
- [ ] 运营看板可见。
- [ ] 开团服务奖励只来自有效开团订单。
- [ ] 普通购买订单不产生开团服务奖励。
- [ ] 退款后奖励应扣减或重算。
- [ ] 提现仍为人工审核 / 手动标记已打款。
- [ ] 税务仍为人工审核 / 占位，不自动报税。
