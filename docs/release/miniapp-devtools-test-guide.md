# 小程序 DevTools 手工测试指南

## 1. 前置条件

- 后端 API 已启动。
- 数据库已准备。
- 有 active category。
- 有 active product。
- 有 active community。
- 有 active pickup store。
- 有 active group buy。
- WECHAT_PAY_MODE=mock。
- MOCK_WECHAT_PAY=true。

## 2. 小程序配置

在微信开发者工具中打开 `apps/miniapp`。如果当前小程序没有 UI 设置 API_BASE_URL，可通过微信开发者工具 Storage 或调试面板写入：

```text
API_BASE_URL = http://127.0.0.1:13080
```

建议同时确认以下 Storage key：

- API_BASE_URL：本地默认 `http://127.0.0.1:13080`。
- mock openid / userId：写入 `community_selection_user`，包含 openid、user_id、nickname。
- 当前选择社区：写入或通过页面选择 `selected_community`。
- 当前选择自提点：写入或通过页面选择 `selected_pickup_store`。

## 3. 用户端测试步骤

1. 商品列表页：进入商品列表，确认商品加载正常。
2. 社区选择页：进入社区选择，选择一个 active community。
3. 自提点选择页：进入自提点选择，选择一个 active pickup store。
4. 商品详情页：点击商品，确认名称、价格、开团入口和普通购买入口展示正常。
5. 下单确认页：从普通购买进入确认页，确认社区、自提点、收货人和手机号可填写。
6. 普通购买下单：提交普通购买订单。
7. mock 支付：确认调用 mock 支付后跳转订单详情。
8. 我的订单页：进入我的订单，确认普通购买订单可见。
9. 订单详情页：查看普通订单详情，确认手机号脱敏。
10. 自提凭证页：从订单详情查看自提凭证。
11. 售后申请页：选择合法售后原因并提交。
12. 售后详情页：查看售后进度。
13. 开团购买链路：从商品详情选择可参与开团，提交开团购买订单并完成 mock 支付，查看订单详情。

## 4. 异常场景

- API_BASE_URL 错误时，页面应展示加载失败或网络错误。
- 未选择自提点时，下单确认页应提示必须选择自提点。
- 手机号格式错误时，下单确认页应提示手机号错误。
- 未支付订单查看自提凭证失败。
- 其他用户不能查看订单。
- 售后 type 不合法会失败。
