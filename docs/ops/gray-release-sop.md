# 首批灰度运营 SOP

## 灰度范围

- 首批只选择 1 个社区、少量商品、少量开团人。
- 首批使用 `core_gray`，会员能力保持关闭；核心链路连续 3 天稳定后才进入独立 `membership_gray`。
- 每日固定时间复盘订单、退款、告警、库存和开团服务奖励数据。

## 每日检查

1. 查看订单数、支付状态、退款状态。
2. 查看 OpsAlertLog 是否有 open 告警。
3. 查看提现申请和税务复核记录。
4. 查看库存是否低于安全值。
5. 抽查 AI context 是否可用于定位问题。

## 暂停条件

- 支付状态与订单状态不一致。
- 退款或库存出现重复处理迹象。
- 告警连续出现且无法人工闭环。
- 数据库备份失败。
